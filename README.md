# Castro Finish Carpentry — Website

Static website for **Castro Finish Carpentry Inc.** — finish carpentry and home repairs on Cape Cod, MA.
Plain HTML, CSS and JavaScript. No framework, no dependencies.

## Pages

| File | Page |
|------|------|
| `index.html` | Home |
| `services.html` | All services overview |
| `trim.html` · `siding.html` · `decks.html` · `windows-doors.html` · `roofing.html` | One page per service |
| `about.html` | Our story (Estevam Castro) |
| `process.html` | How free estimates and projects work |
| `reviews.html` | Google reviews |
| `financing.html` | Project financing |
| `faq.html` | FAQ (general + per service) |
| `contact.html` | Free estimate form, contact details, map |

## Folder structure

```
├── *.html            ← the 13 pages (generated — see "Editing")
├── css/styles.css    ← all styles (brand tokens at the top)
├── js/main.js        ← mobile menu, scroll reveal, form validation/submit
├── assets/
│   ├── fonts/        ← Jost, Lora Italic, Poppins (self-hosted)
│   ├── img/          ← job photos
│   └── logos/        ← Castro seal
└── _build/
    ├── build.py      ← page generator (header, footer, nav, all page content)
    └── pages/home.html ← homepage body
```

## Editing

The header, menu and footer are shared by every page, so the pages are generated by a small Python script (Python 3, no packages needed).

1. Edit content in `_build/build.py` (services, About, FAQ, reviews, contact info…) or the homepage body in `_build/pages/home.html`.
2. Run:
   ```bash
   python3 _build/build.py
   ```
3. Commit the updated `.html` files.

Don't edit the root `.html` files by hand — the script overwrites them. Styles (`css/styles.css`) and scripts (`js/main.js`) can be edited directly.

## Preview locally

```bash
python3 -m http.server 5173
```
Then open http://localhost:5173

## Publish on GitHub Pages

1. Create a repository and upload/push these files (the root of the repo should contain `index.html`).
2. On GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The site goes live at `https://<user>.github.io/<repo>/` in a minute or two.
4. Custom domain (e.g. `castrocarpentryinc.com`): add it under **Settings → Pages → Custom domain** and point the domain's DNS to GitHub Pages.

The `_build/` folder starts with an underscore, so GitHub Pages does not publish it.
